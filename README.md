Explorando Drivers de Comportamiento en NovaRetail+

📊 Descripción del Proyecto
Análisis correlacional de comportamiento de clientes en NovaRetail+ para identificar los factores más asociados al ingreso anual generado por usuarios y apoyar decisiones de crecimiento, retención y segmentación de negocio.

🎯 Objetivos
Identificar variables de comportamiento relacionadas con el ingreso anual.
Analizar patrones de uso, satisfacción, abandono y membresía premium.
Detectar correlaciones relevantes mediante análisis estadístico y visual.
Traducir hallazgos en recomendaciones accionables para negocio.

🔍 Metodología
Exploración y validación de un dataset de 15,000 registros de clientes.
Análisis correlacional con métricas estadísticas:
Pearson
Spearman
Punto biserial
V de Cramér
Visualización de relaciones mediante heatmaps y scatterplots.
Interpretación responsable de correlaciones, limitaciones y posibles sesgos.
Elaboración de reporte ejecutivo orientado a stakeholders.

📈 Resultados Principales
✅ Identificación de variables con mayor relación al ingreso anual generado.
✅ Detección de patrones de comportamiento asociados a retención y abandono.
✅ Segmentación de usuarios según nivel de actividad, satisfacción y membresía premium.
✅ Recomendaciones para optimizar estrategias de crecimiento, experiencia de usuario y retención.

🛠️ Herramientas Utilizadas
Python — análisis y procesamiento de datos
Pandas & NumPy — limpieza y manipulación de datos
Matplotlib & Seaborn — visualización y análisis exploratorio
Jupyter Notebook — documentación y desarrollo del análisis
Análisis Correlacional — Pearson, Spearman, V de Cramér y punto biserial

📁 Estructura del Proyecto
novaretail_analysis.ipynb — análisis completo y visualizaciones
datasets/ — dataset de comportamiento de clientes
charts/ — gráficos y heatmaps generados
